Видео прямо на рабочем столе

Небольшое плавающее окно-плеер для Windows. Данное приложение созданно для прослушивания музыки, многие любят играть, либо тренироваться под эдиты но не всегда удобно включать и искать это в ютубе. Именно для таких людей созданна эта программа, приложение постоянно обновляется и имеет высокую возможность кастомизации. Просто скачай все свои любимые эдиты, закинь в приложение и кайфуй.

⬇ Скачать для Windows Что умеет
Бесплатно · Windows 10/11 · нужен установленный VLC и Python

Возможности

Плавающий виджет

Окно без лишней рамки, которое всегда поверх других программ. Двигается за шапку, размер меняется за любой край или угол — от маленького плеера в углу экрана до большого окна.

  • Кнопка «поверх всех окон» включается и выключается
  • Свернуть, развернуть, двойной клик по шапке
  • Размер и положение запоминаются

Пока видео играет, диск крутится, на паузе плавно тормозит. Стандартный диск можно заменить на любую свою картинку — программа сама сделает её круглой, с отверстием посередине, и позволит выбрать скорость вращения.

Плейлист с обложками

У каждого видео видна обложка — кадр из ролика, ваша картинка или файл с тем же именем рядом с видео. Строки перетаскиваются мышкой: так вы сами выбираете порядок, он запоминается.

  • Новые файлы из папки videos появляются сами
  • Правая кнопка: задать обложку, открыть папку
  • Когда видео закончилось, включается следующее по кругу

Компактный режим

Уменьшите окно до маленького плеера: в узком окне плейлист прячется сам, остаются видео, диск и кнопки. Управление остаётся прежним — пауза, перемотка, громкость, пробел и стрелки на клавиатуре.

Скачать и установить

  1. Установите VLC media player и Python с официальных сайтов (при установке Python отметьте «Add to PATH»).
  2. Нажмите кнопку ниже и распакуйте архив в любую папку.
  3. Дважды кликните СОЗДАТЬ_ЯРЛЫК.bat — на рабочем столе появится ярлык со значком программы.
  4. Положите видео в папку videos и запускайте виджет ярлыком. Всё остальное докачается само.
